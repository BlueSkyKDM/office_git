# xlgit — Excel / PowerPoint をgitのように管理するツール (Linux)

内部で本物のgitを使い、Office文書(.xlsx / .xlsm / .pptx)の「バイナリで差分が見えない」問題を解決します。
.pptx も同じコマンドでそのまま使えます(`xlgit add 資料.pptx` など)。

## 必要なもの
Python 3.8+, git, openpyxl, Pillow, python-pptx (`pip install openpyxl pillow python-pptx`)

## インストール
    chmod +x xlgit.py
    sudo cp xlgit.py /usr/local/bin/xlgit     # もしくは ~/bin に配置

## 使い方
    cd 作業フォルダ
    xlgit init                      # 初期化(gitのtextconv設定も自動)
    xlgit add 売上.xlsx
    xlgit commit -m "初版"
    xlgit commit -a -m "B列を修正"   # 追跡済みの変更を全てコミット
    xlgit status
    xlgit log [--stat] [ファイル]
    xlgit diff                      # 作業ツリー vs HEAD(セル単位)
    xlgit diff HEAD~1 HEAD          # 2リビジョン間
    xlgit show [REV]                # コミットの変更セル一覧
    xlgit cat REV 売上.xlsx          # 過去版の中身をテキスト表示
    xlgit restore REV 売上.xlsx -o 旧版.xlsx   # 過去版を復元(別名)
    xlgit restore REV 売上.xlsx --force        # 上書き復元
    xlgit git branch / checkout -b ...         # その他のgitコマンド
    xlgit web [--port 8765] [--host 127.0.0.1] [--no-browser]   # ブラウザでセル表示の差分ビューア

差分の例:
    ~ 売上!B1: 100  ->  150                                  (セル値)
    ~ [書式等] 売上!A1  font.size: (既定) -> 14.0; font.bold: ...   (書式)
    ~ [条件付き書式] 売上!cf:B1:B4#1  formula: 25 -> 15
    ~ [グラフ] 売上!chart@G2  title: 売上推移 -> 売上(修正)
    ~ [画像] 売上!image@G20  md5: 2cb62c10a7 -> c3de184743
    + [セル結合] 売上!merge:D1:F1  exists=yes
    ~ [列・行] 売上!col:A  width: 20.0 -> 35.0
    + シート追加: メモ

`xlgit init` 後は通常の `git diff` / `git log -p` でも同じ内容がテキストで表示されます。

## Webビューア (xlgit web)
差分を文字ではなく、Excelのセルグリッドのまま表示します。

    cd 作業フォルダ && xlgit web      # http://127.0.0.1:8765/ が開きます

- 左のコミット履歴をクリックすると「そのコミット vs 親」の差分を表示(先頭は未コミットの作業ツリー)
- 上部のセレクタで比較元・比較先・ファイルを自由に選択可能
- 表示は「重ねて表示」(旧値は取り消し線で小さく併記)と「左右に並べる」(スクロール連動)
- 色: 緑=追加 / 赤=削除 / 黄=値の変更 / 青枠=書式のみ変更。セルにマウスを乗せると旧値・新値・書式差分を表示
- 実際の塗りつぶし・太字・文字色・罫線・結合セル・列幅も再現
- 数式セルは計算結果を表示(ツールチップに数式)。Excelで保存済みのファイルが対象
- 右の変更一覧をクリックすると該当セルへジャンプ。「変更のある行だけ」で大きなシートも見やすく
- グラフ・画像・条件付き書式・入力規則・シートの増減などは右下の一覧に表示
- 読み取り専用で、ファイルは書き換えません。認証はないため、通常は 127.0.0.1 のまま使ってください

## PowerPointの差分
    ~ [図形] 1. 事業計画!shape:3(TextBox 2)  pos: 72.0,144.0 -> 108.0,144.0; text: 1億円 -> 1.2億円
    ~ [図形] 1. 事業計画!shape:4(Rectangle 3)  fill: 2E86DE -> E74C3C
    - [図形] 1. 事業計画!shape:5(Picture 4)  ...
    ~ [図形] 2. 数値!shape:4(Table 3)  cell:2,2: 100 -> 150
    + スライド追加: 3. 新スライド

- 対象: スライドの増減・順序・レイアウト・背景・ノート・非表示 / 図形の位置・サイズ・回転・重なり順・塗り・線 /
  テキスト内容と書式(サイズ・太字・斜体・下線・色・配置) / 画像(内容) / 表のセル / グラフ(種類・タイトル・系列・値) / グループ内の図形
- スライドはIDで追跡するため、並べ替えや途中への挿入があっても正しく対応付けられます
- `xlgit web` ではスライドを実際のレイアウトで描画し、変更された図形を色枠で表示します
  (緑=追加 / 赤=削除 / 黄=内容の変更 / 青=位置・書式のみ)。右の一覧から該当図形へジャンプできます
- 制限: アニメーション・画面切り替え・SmartArt・マスター/レイアウトの編集は差分対象外です。
  Webビューの描画は簡易表示で、テーマのフォント継承やグラフの実描画は行いません(グラフは種類と系列名を表示)

## 差分の対象
値・数式・コメント・ハイパーリンク / フォント・塗りつぶし・罫線・表示形式・配置・保護 /
結合セル / 列幅・行高・非表示 / 条件付き書式(ルール・条件・色・色階調・データバー等) /
入力規則 / グラフ(種類・タイトル・軸タイトル・系列の参照範囲・位置) /
画像(内容・位置・サイズ) / シート設定(表示状態・タブ色・ウィンドウ枠固定・フィルタ・印刷範囲) /
名前定義 / シートの増減と順序

## 注意・制限事項
- 画像の検出(xlsx)にはPillowが必要です(`pip install pillow`)。無い場合は画像の増減のみ検出します。
- グラフはopenpyxlが読める項目を比較します。それ以外の細かな変更(色・軸の書式など)は
  「グラフの内部設定が変更されました」と通知されます。
- 差分はセルの書式を「既定との違い」で表示します。条件付き書式の一部(アイコンセット詳細等)は簡略表示です。
- ピボットテーブル、スライサー、マクロ(VBA)、図形・テキストボックスは差分対象外です(ファイル自体は完全に保存されます)。
- Excelファイルの自動マージはできません(-merge指定)。競合時は片方を選んでください。
- 数式の計算結果ではなく数式そのものを比較します(Webビューでは結果も併せて表示)。
- Webビューではグラフ・画像そのものは描画せず、変更内容を一覧で表示します。
- 既存リポジトリで更新した場合は `xlgit init` をもう一度実行してください(設定が更新されます)。
